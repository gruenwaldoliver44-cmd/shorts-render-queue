# Regieplan Weltkrise-Video (Entwurf zur Abnahme mit dem Skript)

Look: Cartoon-Sets aus Higgsfield für Szenen mit Menschen. Dazu gecodete Motion Graphics (Remotion), die modern und scharf aussehen: dunkles Navy, Glas-Panels, leuchtende Linien (Cyan = Geld, Amber = Warnung, Rot = Crash), schnelle Schrift, harte Schnitte, Partikel als Geldströme. Anteil etwa 40 % Motion Graphics, 60 % Szenen. Jede Einblendung bekommt ein SFX (Whoosh, Klick, Glas-Riss, Münze, Stempel, Ticker-Piepen).

Durchgehendes HUD oben rechts: „DEIN FONDS $10,000“ zählt live mit (9.100 → 8.000 → 7.500 → 9.000 → 6.000). Unten links: Domino-Weltkarte, auf der jeder gefallene Stein aufleuchtet.
